# P01 业务路由目标矩阵

| 来源内容 | 目标路径 | 浏览器验证 | 状态 |
|---|---|---|---|
| 记忆引用 `/knowledge/mem_…` | 记忆详情文章 | 真实记忆 ID；点击当前 SPA；无顶层 document 请求；文章含合成事实；刷新及返回原会话通过 | PASS |
| 提醒引用 `/reminders/rem_…` | 提醒详情 | 真实 Vikunja 任务；仅缺时间时点 09:00 Chip 创建；详情标题/ID匹配；刷新及返回原消息通过 | PASS |
| 回忆引用 `/moments/mom_…` | 回忆图片详情 | 当前没有图像授权和生成资产 | BLOCKED_CONSENT |
| 原对话消息 | `/c/{conversation_id}?message={message_id}` | 从提醒详情返回精确来源会话和消息；浏览器保持同应用路由 | PASS |
| 未知或非业务 Markdown URL | 原有外链/下载处理 | 限制 Link 分支不捕获未知路径 | PASS（回归范围） |

测试视口：390、430、768、1440、1920 px。记录到的五个视口均无横向溢出。当前未把“HTTP 200 路由壳”作为详情业务验收。
