# 记忆与语义编排：中文独立验收用例集

> 配合 `MEMORY_IMPLEMENTATION_STATE.md` 的 P5 综合验收使用。每条用例给出「输入 → 预期行为 → 判据」，
> 用于在真实模型 + 浏览器下逐条跑，并把命中/回复/执行/成本/延迟分层记录。真实模型未跑之前，本文件只是用例清单，不代表已通过。

## 运行前准备

- 隔离合成账号（不碰真实用户库与真实 Memos），`memory_consent`、`recall_consent` 开启。
- 规划器与抽取器使用真实模型（`memory_llm_key` 已配置）；嵌入模型用 H 盘本地 BGE。
- 每条记录证据：输入原话、后端 `status`/`retrieval`、最终回复、是否命中、耗时与成本。

## 用例矩阵

| 编号 | 场景 | 输入示例 | 预期 | 判据 |
| --- | --- | --- | --- | --- |
| A1 跨年 | 去年与今年都提到同一主题 | 先存「去年去大理」，再问「我哪年去的大理」 | 只按年份正确回答，不把两年混为一谈 | 回复区分年份；无幻觉 |
| A2 同义 | 不同措辞同义召回 | 存「喜欢喝龙井茶」，问「我平常喝什么饮料」 | 语义泛化命中「龙井茶」 | 命中，不靠关键词 |
| A3 指代 | 代词/省略指代 | 上一轮说「团子」，下一轮问「它多大了」 | 结合上下文识别指代，无法确定时澄清 | 澄清或正确绑定，不臆测宠物/人 |
| A4 纠正 | 覆盖旧事实 | 存「住北京」，后说「现在搬到上海」 | 新事实优先，旧事实不复活 | 回复上海；来源可追溯 |
| A5 撤回 | 明确删除 | 「忘记我刚才说的住址」 | 撤回后不再召回该事实 | 状态 withdrawn；重问不复活 |
| B1 概览 | 一段时间做了什么 | 「最近一周做了什么」 | 按发生日列事件，不经过相似度阈值 | 事件按日列出，分页元数据正确 |
| B2 主观回顾 | 模糊复杂回顾 | 「你觉得我近期最有意思的一件事是什么」 | overview 列出候选并说明是主观判断 | 不把主观判断当事实 |
| C1 混合动作 | 记忆 + 提醒同轮 | 「记下我周五要汇报，并提醒我周四准备」 | 记忆写入 + 提醒草稿分开，不重复写入 | 两个动作各自状态正确 |
| C2 失败状态 | 无命中 | 问从未提过的人 | 明确说无记录，不称「完全没有发生」 | 无幻觉，措辞区分「没查到」与「没发生」 |
| C3 失败状态 | 无权限 | 关闭 recall_consent 后查询 | permission_denied，不返回记录 | 后端状态与回复一致 |
| C4 失败状态 | 规划器不可用 | 未配 `memory_llm_key` | planner_unavailable，回退召回或不答 | 不冒充有记录 |
| C5 失败状态 | 联网不可用 | 问实时天气且未接联网 | 明确「未联网/不可用」，不冒称已搜索 | 无「我搜索到」 |
| D1 引用 | 证据来源 | 命中的记忆带 URL | 回复引用来源链接 | 链接对应授权来源 |
| D2 部分结果 | 分页/截断 | 大量历史 | 明确「部分结果」，不称全量 | has_more/truncated 反映在回复 |

## 分层报告模板

每条通过后用表格记录：`命中数 / 证据数 / 回复是否可读 / 动作是否真实执行 / 规划延迟 / 抽取延迟 / token 成本`。
只有实际跑过真实模型的用例才标记 PASS；未跑标记 NOT TESTED，失败标记 FAIL 并保留原话与后端状态。
