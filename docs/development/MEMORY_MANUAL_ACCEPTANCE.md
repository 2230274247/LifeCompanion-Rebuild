## 登录

- 入口：<http://127.0.0.1:3001>，只在这台运行服务的电脑上使用。
- 账号文件：仓库内 `infra/runtime/p5/lc-account.json`；`email` 是登录邮箱，`password` 是密码。
- 该文件是既有、被 Git 忽略的隔离测试账户文件，本次已实际登录成功；无需注册，也不要把服务 Token 或 Memos PAT 当密码。
- 不在说明、验收日志或证据中复制密码。本轮未更换密码，也未复制新凭据文件。
- 使用浏览器无痕窗口可以避免和其他环境的登录状态混淆。

## 账户数据

本轮添加了 **120 条合成历史**，覆盖 **2025-11-02 至 2026-10-20**，每月10条，主题包括出游、做菜、读书、学习、运动、音乐、园艺、家庭、志愿服务、手工。

验收时账户共有 **125 段已发布回忆**，包括这120条和5条既有/本轮探针记录。后续自己聊天可能使数量变化。合成条目正文标有“合成验收历史”；不是实际个人资料。

120条经现有认证手动抽取 API 添加，采用离线抽取，再通过实际 Memos 发布与读取。它们用于验收检索、日期与显示，**不能算120条真实DeepSeek抽取成功**。聊天问答使用真实DeepSeek；此前真实聊天自动抽取另有独立证据。本轮没有伪造历史AI回复，也没有创建12个虚假的历史对话。

## 推荐验证步骤

1. 登录后进入“我的回忆”，应看到约125段；点击“下一页”，地址出现 `page=2`，内容随页变化。当前界面默认每页20条；本轮API另用每页50条读取3页，125个事件无重复。
2. 展开“日期与排序”，选择 `2026-10-02`，应只显示林晓同行的杭州龙井村回忆。也可直接打开 <http://127.0.0.1:3001/memories?on_date=2026-10-02>。
3. 打开这条回忆，应显示日期、实际 Memos 正文和“合成验收历史”。该条是手动导入，没有来源聊天链接是正常的。
4. 每个问题使用一个新对话，复制下面的问题，观察事实与引用；点击引用应能进入对应记忆详情。
5. 再自己说一件今天发生的合成经历，等待提取后，在新对话询问它，检查是否真的进入回忆，而不只是在原对话里回答。

| --- | --- |
| 2026年10月2日，我和林晓去了哪里？ | 杭州龙井村；有记忆引用；7.31秒 |
| 2025年11月，我在读书会分享了哪本书？ | 《小王子》，11月6日；有记忆引用；7.22秒 |
| 请回顾2026年10月的生活记录，按活动整理，并说明本次查到了多少条。 | 10条，含龙井村、栗子烧鸡、《苏东坡传》、手冲咖啡等，10个引用，并说明覆盖边界；6.19秒 |

这三个耗时是本机本次样本，不是平均延迟或稳定性承诺。三个成功问题也不代表任意问题100%正确。原始结果及截图见 [本轮证据](../../evidence/memory-demo-20261110/README.md)。

## 验证纠正、撤回与动作时

- 撤回会改变这个测试账户。若要练习，先新增一条专门的合成记忆，再纠正或撤回它，避免删除这批固定验收样本。
- 撤回后用新对话查询；原始聊天文本不会因为记忆撤回而自动消失，不能只看旧对话判断是否失效。
