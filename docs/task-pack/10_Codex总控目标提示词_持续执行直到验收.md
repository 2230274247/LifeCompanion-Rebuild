## 二、业务终局（完成这些才叫产品功能真正齐备）

1. **真实拟人化聊天**：借力 Rebuild 现有 LibreChat 或等价成熟开源核心，真实云端模型、消息持久化、历史恢复、正确 Markdown/UI、无内部状态泄漏、统一登录与路由。
2. **智能长时记忆**：将用户授权的聊天记成可纠错事实、人物、关系、事件，跨会话多候选检索；来源可追溯、不乱合并、不将短时对话上下文伪装成长期记忆。
3. **真正执行提醒**：自然语言识别；已知信息自动填、缺什么问什么；用户明确指令可一次点击完成，潜在日程需同意；持久任务、可修改取消、重启恢复，实际到点通知且诚实报告送达状态。
4. **三时段无感回忆生图**：获得长期授权后，按用户时区早/中/晚窗口自动从真实事件记忆筛选代表事件；无有效内容可 0 张；经真实图像服务生成、文件保存并静默进入“我的回忆”，图片可回查来源且标注 AI 创作。
5. **确切生活帮助**：具备可靠资料搜索、天气、路线与出门建议的可审计工具链；支持授权语音、方言能力需实际测试；轻量定时/事件回访与静默频控。
6. **连接人与人**：家人/伴侣/朋友关系邀请、双方认证、最小必要范围共享、可撤销的温馨关心请求与可选回忆；不得因为 AI 知道用户日程就默认向别人展示。
7. **产品级稳定性**：后台用户/日志/成本/提醒/记忆/回忆/授权管理；统一身份与消息源、可靠迁移、备份恢复、开源许可证、Windows/Ubuntu 部署、安全/性能/可访问性真实验收。

目标同时包含用户的初始愿景与后续修正，不允许偷偷删除“静默自动生图”或“家庭连接”以便更早报告完成；但可以通过阶段门禁交付核心功能，远期能力继续跟进。

## 四、严格执行次序与每阶段不可省略的验收

按以下顺序阅读、实施、真实运行和验收：

```
P00  唯一仓库身份/旧成果审计/守卫/真实基线
P01  真实聊天、统一用户身份、业务卡跳转、UI基础体验
P02  LangMem+Neo4j 长时记忆/证据/跨会话检索；Graphiti能力门禁
P03  Vikunja/现有任务服务+LangGraph+APScheduler+ntfy 真提醒
P04  时间窗事件智能选择+真实图像服务+静默相册
P05  网页查询/天气路线/回访/语音
P06  家庭双方授权、可撤销共享、关心请求
P07  后台、运行监控、性能/安全、备份、Ubuntu部署、全量回归
```

每一阶段都必须：

1. 重新核验当前 Rebuild 根目录、branch、HEAD、未提交变更、隔离测试 DB、第三方服务身份。
2. 定位该阶段现有功能：`ALREADY_WORKING / PRESENT_BUT_BROKEN / NOT_IMPLEMENTED / DUPLICATED / CONFLICT`，给源码与运行证据。
3. 优先 clone/获取成熟上游的**被批准版本**到隔离目录或使用受控镜像/包；核查 LICENSE/NOTICE、兼容/安全；调用实际 API，禁止仅 clone 宣布完成。
4. 最小化增量修改，保留原框架并定义数据 Schema、跨服务 ID、状态机、授权、失败恢复；不无故大重构。
5. 编写或移植最小可复现测试；运行单元、真实集成、端到端浏览器、负路径、服务重启与回归；保留真实报错与成功证据。
6. 遇普通 bug、依赖冲突、可恢复错误，自动分析→修复→重跑，直到阶段验收满足，不要因第一次测试失败便只报告建议。
7. 每阶段生成**新的** `PXX_STAGE_LOG.md`（不要覆盖前次日志），列 Git Diff、改动文件、运行命令/退出码、日志/截图/真实 API/DB 证据、成本、原始数据安全检查、全部未通过与风险。
8. 更新 `11_跨阶段总验收矩阵.md` 的每个验收编号状态，只有 Rebuild 真实运行且达到标准的项目可以写 PASS。
9. 阶段输出小结+下一阶段接口契约；随后继续可开展的下一阶段，不要再次把所有工作停留在计划文件。

## 五、持续自驱修复循环（不是危险的无限执行）

对每个 `FAIL/PARTIAL` 项目，在**当前已批准资源和权限范围内**循环：

```
读取真实证据 → 找到最小失败路径 → 列出根因假设 → 最小修复
→ 真实运行相关测试 → 运行不相关模块回归 → 更新证据和日志
→ 若未达标则继续下一个修复循环 → 若达标进入下项
```

- 不通过修改测试预期、删测试、用 Mock 冒充实测、给前端写固定“成功”文字、复制旧验收报告制造 PASS。
- 任务较长时维护 `WORK_LOG.md`、`NEXT_ACTION.md` 与阶段断点，记录已完成命令、运行环境、阻塞、后续操作，避免上下文压缩后丢失进度；当前会话/执行预算允许的范围内持续推进，不声称可以无限后台自动运行。
- 可以自动修可恢复代码错误；但如发生**项目身份不明、需要新付费账户/额外费用、生产数据破坏/迁移、隐私越权/密钥暴露、法务/许可证无法满足、未经授权公网部署**，必须停止相关高风险步骤并报告 blocker，不能为了“不停止”绕过安全门禁。其他互不依赖阶段仍可继续。
- 外部图像/地图/语音 Provider 的许可/密钥/网络不可用时，完成内部可验证管线、适配器、失败态与不需 Provider 的其他模块，留 `BLOCKED_PROVIDER`，不得写“整个产品100%完成”。
