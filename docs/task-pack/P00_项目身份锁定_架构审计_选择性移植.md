# P00｜项目身份锁定、现状审计、旧成果选择性移植（第一个交给 Codex）

## 目标与理由

过去出现**把旧 Silver-economy 的 worktree 当成主项目**的风险。本阶段要识别真正承载聊天/记忆/回忆/提醒网页的项目、进程、数据库和工作树，并把未来每一步写操作限制在 `H:\AI For research institute\LifeCompanion-Rebuild` 所对应的**唯一 Git 仓库**。本阶段在完成审计前只能做只读动作。

## Codex 实施任务

### 00-01. 识别文件系统与 Git 身份

1. 在 Windows 中分别读取候选三个项目（真实存在的才检查）的绝对路径、目录元信息、`git rev-parse --show-toplevel`、`git rev-parse --git-common-dir`、`git remote -v`、branch、HEAD、`git status --porcelain=v1`、`git worktree list --porcelain`。
2. 旧 `.work/intelligence-20261103` **只读**核实所报告 119 文件变化的实际清单、commit、未跟踪文件和可复现测试。119 不可作为当前真实数量预设。
3. 区分 Rebuild 是否完整 Git 仓库、子模块、Git worktree、打包快照；其根目录含有被验证的产品代码才可锁定。只看同名目录/Logo/网页 title 不能算验证。
4. 生成 `PROJECT_IDENTITY_AUDIT.md`、`WORKSPACE_LOCK.json`、只读 `UPSTREAM_BASELINE.md` 盘点；密钥与敏感连接串只存布尔存在性和脱敏指纹。
5. 实现并**实际调用** `verify_rebuild_workspace` 守卫，任何 shell、脚本、子 Agent 和迁移入口都先运行它。守卫使用绝对路径+`git common-dir`+业务标记，不仅判断当前文件夹字符串。锁定文件应支持经审计的 Rebuild 外部 worktree，但拒绝其他 Git 仓库。

### 00-02. 找出当前“用户看到的页面”究竟从哪里运行

- 只读调查 `docker compose ps` / 已存在容器配置/监听端口、前端构建产物、API Base URL、反向代理、浏览器页面加载来源、SSE/WebSocket、任务和数据库实际连接（脱敏）。
- 识别 LibreChat、Memos、life-core、Mongo、Meili、Vikunja、ntfy、Neo4j、LangMem、LangGraph、Graphiti、APScheduler 是否已经存在、版本、连接与调用入口。
- 对 Rebuild 中已有登录与 `user_id` 映射、数据主库、会话主库、记忆库、Memos/提醒平台写入权限，绘制“浏览器→API→持久化→后台任务→第三方服务”的实时数据流。
- 核查当前的测试账号是否真存在于本项目（不要读取、打印或扩散密码），核查测试/生产账号和数据库是否隔离。

### 00-03. 两套旧项目的可移植成果审计

- 建 `SELECTIVE_PORTING_MATRIX.md`，每一项具备 `source_repo / commit / src / license / risk / current_Rebuild_overlap / decision / target / required_test / final_result`。
- 优先移植：稳定纯函数、Pydantic Schema、时间解析和对话状态机测试、权限门控、意图标注集、故障复现样例、回忆质量评分测试、图谱合并规则。全部按 Rebuild 接口重测。
- 不直接移植：旧 ORM/Mysql 数据库 schema、整套 Vue 页面、旧 Compose/端口/环境变量、用户记录/素材、旧版 `.env`、node_modules、.venv、未经审查的上游源修改。
- 每项必须评估：与 Rebuild 原生功能是否重叠、开源许可、软硬依赖、配置和成本、信息安全与维护性。

### 00-04. Rebuild 基线回归和故障复现

先在隔离环境真实启动可运行的现有服务。记录版本、构建、所有原有自动化测试的真实统计，至少复现：

- 真实模型聊天、刷新历史、切换不同会话；
- 从聊天点开“提醒/记忆/回忆”并返回；
- “明天提醒我带绿色 U 盘，不是银色的”能否成功形成任务；
- 在新会话问前一会话的 U 盘、雨伞两条事实；
- 日历/相册中的图片是否真有文件资产；
- 取消任务后重新登录是否仍取消；
- 测试账号跨用户能否越权读取业务实体；
- 是否存在缺陷：Markdown 星号、Enter 后残留、思考内容暴露、导航重新整页加载、时区错误。

不能在隔离环境复现时标 `UNKNOWN` 并保留复现步骤和所缺条件，不强行诊断。
