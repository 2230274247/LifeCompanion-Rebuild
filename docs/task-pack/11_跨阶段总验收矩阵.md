## 按场景计算完成度，不按代码量

本矩阵共有 **73 个测试点**。完成率 = 本轮在 **Rebuild** 真实验收为 PASS 的测试点数 / 总数；单元测试、Mock、其他项目结果不能替代它。阻断项必须单独列出，不能从分母中悄悄删除。

## 额外绝对门禁

- 未经确认创建正式提醒、跨用户越权、未授权生图/家庭共享、生产数据被污染、API Key 泄漏：出现任何一例即整体安全 `FAIL`。
- 用户明确要求静默图片，而产品却默认发完成通知：`MOM-06` 失败。
- 缺合法图像/地图/语音 Provider：相关真实性验收只能 `BLOCKED_PROVIDER`，不能用 Mock 通过。
- 无真实 Embedding API 时 Graphiti 原生查询不许标 `PASS`；独立记忆的 Neo4j 无向量查询可单独通过。
- 每条“已完成”都必须有至少一项本轮运行证据：代码版本、命令/退出码、API/DB状态、真实浏览器截图或录屏。
