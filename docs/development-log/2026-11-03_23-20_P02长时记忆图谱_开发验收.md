## 失败与修复记录

- 第一次 Neo4j 启动因 env 文件中 `NEO4J_PASSWORD` 被误当作 Neo4j 配置项而退出；移除该项并从 `NEO4J_AUTH` 解析健康检查后启动正常。
- 首次 Graph projection smoke 发现 Evidence 的 `evidence_date` Cypher 属性赋值有误；修复后真实写入、查询和撤回均通过。
- 第一次 P02 查询同时返回 U 盘和雨伞是通用的“明天带什么”预期；U 盘限定查询最初也包含雨伞，根因是未使用 key 内 topic 限制。已增加 topic filter，完整 E2E 重跑通过。
- 早期模型探针在 PowerShell inline source 下中文被编码破坏；改用 Unicode escape 后验证真实结构化输出和原文子串一致。
- 重复模型实测没有每次都返回实体，图关键词检索现已支持直接检索记忆正文，不依赖模型必定生成实体。
- 撤回图数据最初只删除了 Memory 节点，遗留来源节点与实体间关系；已修复并实际验证相关用户节点为 0，另一用户的 4 个节点保留。
- 同步进行中的撤回可能被旧任务成功回执覆盖；增加 generation 条件与事务领取后，真实图写入后再撤回的交错验证通过。
- 模型一次返回畸形字段并触发 LangMem/Trustcall 验证修复，最后成功；证明结构化输出并非始终一次有效。没有据此声称结构化有效率 100%。
