## 2. 目标与边界

原问题：用户先要“浏览器旁边的小宠物”，随后明确修正为
“放到我的软件页面里面，打开才会显示那种”。因此交付物必须满足：

- 宠物活在 Life Companion 页面内部，随页面打开而出现、关闭而消失；
- 形象是 Otis 的可拉伸脸，不是此前误做的 murmur 玻璃球；
- 能捏、能拉：抓脸颊变 `being squeezed`，抓头发 `g_squish`，拉下巴 `g_grimace`，
  持续拉拽让耐心条归零后出现 `x_dizzy`，松手回弹并随机换一张 release 表情；
- 不遮挡聊天输入框、发送按钮与回忆页面的筛选控件。

明确排除：

- 不做常驻置顶桌宠（上一轮 Electron 实现保留为可选实验，不再是交付入口）；
- 不把宠物心情写入数据库，不与聊天、回忆、提醒状态联动；
- 不做触屏与键盘操作，不做手机端展示；
- 不修改 Otis 的 WebGL 引擎行为。

## 3. 架构实现

### 3.1 代码位置与挂载点

```text
products/librechat-custom/client/src/
  components/Life/OtisPet/
    OtisPet.tsx          组件外壳：布局、折叠、提示、心情条、指针穿透
    otis-pet.css         布局与动效（不放主题色）
    content.ts           原 Otis 内容，仅把贴图改为 Vite 静态导入
    face/engine.ts       原引擎，逐字复用
    face/FaceCanvas.tsx  原画布组件，仅新增 ariaLabel 与兜底色
    faces/*.webp         14 张表情贴图（2.5MB）
  routes/ChatRoute.tsx   仅在聊天路由挂载 <OtisPet />
```

挂载在 `ChatRoute` 的聊天树内，而不是 `Root`：上一轮放在 `Root` 时，
宠物在 `/memories` 会压住“查询回忆”筛选按钮。移到聊天路由后，
`/memories` 上 `petCount` 为 0。

### 3.2 与上游源码的差异（有意保持最小）

| 文件 | 差异 | 理由 |
| --- | --- | --- |
| `content.ts` | `/faces/*.webp` 绝对路径 → `import ... from './faces/*.webp'` | 页面由 LibreChat 服务，不再有独立静态根目录 |
| `FaceCanvas.tsx` | 新增 `ariaLabel` 属性；兜底圆盘从 `bg-disc` 类改为内联 `backgroundColor` | 无障碍可读；`bg-disc` 是原作品集的 Tailwind 主题类，定制端没有 |
| `engine.ts` | 无 | 交互行为必须与原版一致 |

### 3.3 指针穿透

画布命中层是 200×200 的方框，但脸只占圆盘的一部分。`useFacePassthrough()`
用 `faces.base.src` 生成 256px 的 alpha 掩码，在 `pointermove` 时读像素，
把命中层的 `pointer-events` 在 `auto`/`none` 之间切换：按在脸上是拉脸，
按在空气上是点页面，两者不冲突。矩形外的区域不拦截任何点击。

### 3.4 主题、动效与文案

- 心情条使用语义类：`border-border-light`、`bg-surface-primary/85`、`text-text-primary`、
  `text-text-secondary`、`bg-border-light`，浅色与深色主题各自成立；钴蓝 `#2f4bf0`
  是角色本身的固定色，不套主产品的雾青苔绿 Token。
- 文案全部走 `useLocalize()`：`com_ui_otis_hint`、`com_ui_otis_mood`、
  `com_ui_otis_hide`、`com_ui_otis_open`、`com_ui_otis_aria`，
  只按上游贡献规范写入 `locales/en/translation.json`。宠物台词本身
  （`pull my face`、`chill`、`being squeezed`）沿用 Otis 原设计，刻意保留英文。
- `prefers-reduced-motion` 下关闭提示、圆环与耐心条过渡。
- 视口宽度小于 900px 时整只宠物隐藏，避免与手机端输入区重叠。
- 折叠状态写入 `localStorage['life-otis-pet-collapsed']`，刷新后保持。

### 3.5 构建与发布链路

LibreChat 容器挂载 `products/librechat-custom/client/dist`。改完客户端后必须
重新构建并重启容器，否则容器返回的是旧 `index.html`：

```text
npm run build                # turbo，前端约 47s，全量约 2 分钟
docker restart lifecompanion-librechat
```

本轮构建后服务的入口包从 `index.DMOl...` 变为 `index.HvKSl7sh.js`，
说明新产物已经生效。

## 5. 功能结果

已完成并实测：

- 打开 `/c/new` 或任意会话页，宠物出现在聊天区右下角（1440×900 下
  `x=1224, y=508, 200×256`），位于输入框下方之外，不遮挡发送按钮；
- 在脸上按下拖动：脸颊被拉成长管，心情切到 `being squeezed`，耐心条下降；
- 松手：回弹并随机切到 release 表情（本轮实测到 `cackling`、`unconvinced`）；
- 点击鼻子：惊吓表情；持续拉到耐心归零：`seeing stars`（桌面实验阶段已验证
  同一引擎路径，页面内本轮未单独截图）；
- 点提示条右侧的 `×`：折叠成 54px 圆头像，再点展开；刷新后保持折叠状态；
- 空白处与脸上的透明像素不拦截点击，输入框、侧栏、消息气泡均可正常操作；
- `/memories` 页面不渲染宠物；
- 浅色、深色主题下心情条底色分别为 `rgba(250,246,234,0.85)` /
  `rgba(13,13,13,0.85)`，文字 `rgb(29,43,37)` / `rgb(236,236,236)`，均可读；
- 1920×1080 与 1440×900 位置一致；390×844 下 `display: none`，移动端不受影响。

未完成 / 未验证：

- 宠物只有指针交互：不可 Tab 聚焦，触摸屏未适配；
- 耐心值与心情不持久化，刷新即回到 `chill`；
- 页面内未单独复测“耐心归零 → `x_dizzy`”的完整长拉（引擎与桌面阶段一致）；
- 长时间打开时的 WebGL/GPU 占用未测量。

## 8. 遗留风险

1. **授权未明**：Otis 源码与贴图来自用户提供的 `otis.zip`，压缩包与参考站点
   均未附 LICENSE，贴图再分发权利不清晰。当前只在本机使用，不进入公开仓库或对外交付。
2. **类型检查被既有改动阻断**：`Moments.tsx` / `V023.spec.tsx` 引用了尚未实现的
   `lifeService.publishMoment`，`npx tsc --noEmit` 整体返回 2。该文件不在本轮
   改动范围内，未擅自补齐 API，以免与进行中的“回忆发布”改动冲突。
3. **可访问性**：宠物是纯指针交互的装饰组件，没有键盘入口；屏幕阅读器只能读到
   `role="img"` 的 `aria-label`。折叠按钮与关闭按钮本身是真实 `<button>`。
4. **性能**：14 张 webp 共 2.5MB，首次进聊天页会加载；WebGL 以 60fps 持续绘制，
   本轮未测长时 GPU 与电池影响，必要时可降到 30fps 或页面不可见时暂停。
5. **文案语言**：中文界面下宠物台词仍为英文（`pull my face`、`chill`），
   这是原设计的有意保留，不是漏翻；如需中文需单独确认语气。
6. **既有 403**：普通测试账户访问 `GET /api/tags` 返回 403，是改动前就存在的
   权限配置问题，与本任务无关，未处理。
7. **桌面实验仍在仓库**：`apps/otis-pet/`（Electron 常驻置顶窗）保留为可选实验，
   不再是交付入口；murmur 旧证据 `evidence/pet-window/` 与其补丁按早前的删除请求
   未能移除（权限策略拦截），需要时可人工清理。

## 9. 结论

总体状态：**PASS**。应用内 Otis 已构建、部署并在真实浏览器中以普通测试账户验收：
出现在聊天页右下角、可捏可拉、可折叠、深浅色主题可用、回忆页与移动端不受影响。

可用性：界面可用，不影响现有聊天、回忆与提醒流程。

是否进入下一阶段：可以。若继续，建议按优先级处理：补齐 `publishMoment`
后恢复全量类型检查 → 为宠物增加“页面隐藏时暂停渲染” → 确认贴图授权后再考虑对外。

人工复核要求：请打开 `http://127.0.0.1:3001` 的聊天页，用鼠标拉脸颊并松手，
确认手感与位置符合预期；并确认允许保留 `apps/otis-pet/` 桌面实验。
