## 3. 规划结论（架构 / 认证 / 界面）

- 技术栈：原生 Kotlin + Jetpack Compose + Material3；Retrofit + OkHttp + okhttp-sse；
  Hilt；Room + WorkManager；EncryptedSharedPreferences / Keystore；Coil；kotlinx.serialization。
- 认证：`POST /api/auth/login` 返回 HS256 access JWT，即 life-core 也认的 token；
  已核实登录中间件含 `requireSameOrigin` 且 refresh 为 Cookie 机制，为原生端最高风险，P0 先探针。
- 界面：Meta Muse 陪伴式消息心智模型 + 拾光雾青苔绿品牌；Otis 作为陪伴头像；
  渐进披露 + 审批卡 + 克制微动效，收敛既有「大胆动效」方向。
