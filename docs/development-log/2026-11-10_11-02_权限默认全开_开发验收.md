# 权限默认全开：独立开发验收

## 基础信息

- 任务：用户要求“所有隐私/权限内容暂时默认全开，用户可自行关闭，便于测试和修改”。
- 日期：2026-11-10；分支 `claude/epic-goldwasser-ad14c0`，紧接“发生日期归属修复”提交（`49595be`）。
- 范围：仅调整新用户/缺失行的默认姿态为“开”，权限门控逻辑本身不变，用户仍可逐项关闭。

## 目标与边界

把 `users`（memory_consent、image_consent）与 `memory_permissions`（recall_consent、sensitive_consent、notification_consent）的默认值从 0（关）改为 1（开）；bootstrap / 提醒用户兜底建号、`permissions()` 缺失行回退、`BootstrapUserRequest` 默认值同步为开；bootstrap 端点统一返回 JSON 布尔。

不改变既有门控判定、不迁移真实用户库（存量用户保持原值）、不新增权限项、不触碰发生日期逻辑。
