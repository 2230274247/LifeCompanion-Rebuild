## 目标与边界

此前 A5“忘记住址”只出现口头回复，来源仍可召回。目标是聊天实际执行撤回、清空来源/派生内容/向量/任务，关联 Memos/Moments 清理、新会话与原话重放不复活，并保留独立来源偏好。

保留好友模块，复用 LibreChat 聊天和 Memos 官方 API；使用已有密钥但不输出、归档凭据。服务只绑定本机，采用隔离合成 SQLite/Mongo/Memos。所有权重使用 H 盘已有固定 BGE 缓存，不下载模型。未修改 Silver-economy、其它工作树、正式数据库或正式入口。

本轮不修发生日/记录日混淆、混合提醒、宠物抽取或大历史召回，不删除原始 LibreChat 聊天。

### 真实撤回结果

4 条种子分别为旧北京住址、新上海徐汇住址、独立龙井偏好、徐汇新家乔迁事件。最终证据见 [9 步记录](../../evidence/memory-forget-20261110/final-cases.json)。

- 撤回前聊天可答徐汇区；相同茶类问题可答龙井茶。
- 真实选择器对否定、假设、引用三种请求均返回 `not_requested`，派生记忆不变。
- 聊天发送“忘记我刚才说的住址”，出现真实 `forgotten` 回执：3 个记忆、3 个来源；来源正文 NULL，派生文本和值为空，事件 withdrawn/摘要清空；向量只保留独立饮茶偏好，所有任务 payload 清空。
- 随后全新会话询问住址，不再给出原住址；同一茶类问题仍答龙井茶。
- 原住址换消息 ID 重放返回 `revoked / SOURCE_REVOKED`。
- 撤回前乔迁事件 published 且有 memo_ref；撤回后官方认证 GET 404。未种入真实 Moments 内容，不能把复用清理路径的单测等同 Moments 实机通过。

## 失败、修复与保留证据

1. 首次真实规划生成非法 `target`，严格模式拒绝，没有实际删除，但模型口头承诺不再保留。保留 [首次失败](../../evidence/memory-forget-20261110/first-attempt.json)。通过精确 JSON 提示修复，同时在召回命中、无命中、异常等上下文统一限制无回执确认；没有放宽 extra=forbid。
2. 第二轮撤回成功，但宽泛“我平常喝什么饮料”未命中仍在库中的龙井偏好。保留 [第二轮记录](../../evidence/memory-forget-20261110/second-attempt.json)。最终使用同一茶类查询做前后对照；未把宽泛召回差异伪报成功或偷偷加入关键词兜底。
3. 一次上游回归因新增提示位于 JSON 后，使原证据序列化测试失败；改为前置约束，保留原证据 JSON/预算合同，57 项重跑通过。
4. 初次 lint 从父目录运行找不到配置/插件；改为上游工作区 cwd，修复两处嵌套三元表达式，最后 lint/type/build 均通过。
5. preview 将 3811 判断为占用并给包装器分配 3812；Docker 实际仍绑定 3811，验收访问实际 3811。只重建本轮 `p5-librechat-withdraw`，没有停止此前被拒绝停止的三个容器。

## 风险、未验证与结论

A5 本轮限定用例 PASS；整套 P5 仍 PARTIAL，不覆盖之前 14 项矩阵。原始聊天独立保留；未为旧会话所有后续模型上下文实现系统屏蔽。无回执不得确认依赖模型约束，真实提供方故障注入后的回复未实测。候选任一类别超过 80 条返回 `FORGET_SCOPE_TOO_LARGE`，尚不支持大历史分页撤回。完整来源闭包清理会一并撤回同一句原话派生的其它信息，独立来源保留。

Memos 故障重试注入、真实 Moments 清理、浏览器聊天及正式环境升级/回滚未测。隔离聊天服务原有 RAG 与 schedules 未配置提示不在本轮修复范围。下一续接点是评估旧会话上下文屏蔽和大历史撤回边界；原 P5 的发生日/混合提醒等问题仍需独立任务，未在本轮实施。
