## 6. 受限 MIME 回退

本次仅在显式开启以下环境变量时使用回退：

```powershell
$env:SILICONFLOW_ALLOW_GENERIC_BINARY_MIME='1'
```

该开关默认关闭。回退不等于放宽全部图片校验，只有同时满足以下条件才可使用：

1. 下载声明严格等于 `application/octet-stream`。
2. 图片 URL 为 HTTPS、443 端口、无 userinfo、无跳转。
3. DNS 结果全部为公网地址，host 属于可信 `*.siliconflow.cn`。
4. Magic bytes 识别为 PNG、JPEG 或 WebP。
5. Pillow 实际格式与 magic bytes 一致，且属于白名单。
6. Pillow `verify()` 通过，第二次打开后 `load()` 完整解码通过。
7. 请求尺寸必须严格为 `960x1280`。
8. 最大 20 MB、最大 20,000,000 pixels，并通过非空白方差阈值。
9. 保存文件重新计算 SHA-256，且与下载字节一致。

以下情况仍严格拒绝：

- 缺失 `Content-Type`；
- 任意不匹配的 `image/*` 声明；
- 不可信 host 的通用二进制响应；
- 伪造 magic bytes、损坏或截断图片；
- 尺寸、格式、像素数、字节数或质量检查失败。
