# 纯语义记忆召回与历史压力验收

更新日期：2026-11-09。适用范围：life-core 的个人知识召回与 LibreChat 的授权记忆注入。实测结果以本次独立开发日志及 `evidence/memory-load-20261109/` 为准。

## 召回合同

1. 每个非空聊天用户回合均调用记忆服务；没有固定提示词门槛。
2. 先核验当前用户、召回授权、active 状态及敏感授权。向量内容也受同样边界约束。
3. 对该用户的全部合格记忆建立持久向量索引。编码批大小仅决定分批计算，不能截断可搜索记忆数量或排除旧记忆。
4. 候选打分只依赖神经语义表示的余弦相似度。不使用分词重合、字符 bigram、关键词、同义词表、实体字面匹配或词面兜底。
5. 用户明确提供的日期是结构化时间约束，不是内容相关性分数。四个验收时段各100条；带具体日期的问题只搜索该日100条，无日期问题搜索400条。
6. 索引不完整、模型不可用、维度异常均明确返回 unavailable；不能伪装成 no_match，也不能改用关键词。
7. 常用资料 profile 是单独标识的受限背景；详细事件 items 依语义相关性返回。profile 最多4条、1200字；items 最多8条，聊天注入总序列化预算另受6000字符限制。重要性不覆盖语义相关性。
8. 最近用户上下文只在当前会话范围内使用，不混入助手生成的事实。撤回指令在截断上下文前检查。无明确指代上下文时不猜测唯一实体。

## 模型与离线准备

当前默认使用固定revision的 `BAAI/bge-large-zh-v1.5-pinned-q8`，1024维、CLS池化，默认余弦阈值0.48。
模型通过 `scripts/evaluate-memory-bge-large.py` 显式下载、校验与准备，文件在gitignored模型缓存中；
运行查询不联网、不下载、不自动回退小模型。原有BGE-small模型仍可显式配置，阈值需按模型重新评估。
`LIFE_MEMORY_EMBEDDING_MODEL`、`LIFE_MEMORY_SEMANTIC_THRESHOLD`、`LIFE_MEMORY_EMBEDDING_CACHE`分别控制模型、阈值与缓存。
完整比较、许可证及原始失败结果见验收证据；校准题集不等于独立生产准确率。

## 持久化与授权

`memory_vectors` 以 `(user_id, memory_id, model)` 为主键，保存内容哈希、维数与向量。读取时同时检查记录仍合格、哈希匹配和维度有效，不能通过旧向量复活撤回内容。

清理不再局限于当前模型：同一用户的旧模型向量若已失去授权、记录已撤回或内容改变，同样清理；不影响其他用户。索引写入在编码后重新核查当前授权和内容。后台索引调度的短锁与模型索引计算锁分开，避免请求线程等待整个批次完成。

## HTTP 边界

- `POST /api/v1/knowledge/recall`：公开的已登录用户接口，用户所有权只取 JWT，禁止请求体指定 `source_user_id`。支持 query、conversation_id、source_message_id 和最多4条最近用户文字。
- `POST /internal/v1/knowledge/recall`：LibreChat 服务端使用的内部接口，仍要求内部认证。
- 网关只放行公开方法，继续拒绝内部 hooks，并移除客户端提供的 `X-Internal-Token`。
- 返回明确状态及 mode=semantic_only、keyword_retrieval=false、候选数、索引数和语义分数。诊断只存机器码、计数和来源ID，不存真实聊天原文或服务凭据。

## 历史合成数据

隔离 owner 和 outsider 账号通过正常注册登录创建。通过受控系统导入，为 owner 写入400条生活、工作、学习合成记录，并在 MongoDB 保存400条来源消息、40个历史会话。历史时间采用用户时区；一个月前按日历月计算，不固定为30天。

导入前使用 SQLite 在线备份；数据和来源ID幂等生成，不覆盖真实账号资料。测试密码和 JWT 只留在 gitignored runtime，合成题集和无秘密报告才进入 evidence。

32条事件被选为回忆候选；选中、SQLite事件存在、Memos发布成功是不同状态。只有官方Memos API实际创建并验证了PRIVATE回忆，才能记为published。本轮服务凭据相关发布操作受到自动审批拦截，不能以伪造memo_ref或修改状态代替发布。

## 验收边界

受控向量测试证明合同、权限和来源处理；真实本地模型的改写题集衡量召回质量；真实聊天验证服务调用及模型回复。三者分别记录，不以单元测试代替泛化准确率，不以手工写入的delivery遥测冒充实际模型输入抓包。

真实聊天已经在不同新对话中验证昨天和一个月前的记录回复及来源链接；这仍不是对完整云端请求体的独立抓包。原有好友、共同回忆、共享空间与授权接口保留其原边界。
